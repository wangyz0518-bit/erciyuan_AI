## 目标与现有基础

先为龙角角色制作一段能在正式 Flutter App 中离线循环播放的 Seedance 待机视频。待机样片通过后，沿用同一立绘和构图制作倾听、思考和说话。本阶段以 `apps/mobile` 的龙角动作预览和沉浸聊天为验证入口，生成和转码在素材制作端完成。

现有龙角播放器使用本地 MP4 和 WebP 封面，视频区域为 `5:6`。沉浸页独立绘制背景，并对人物视频的上、下边缘做渐隐。现有四个对话状态的片段均为 `480 × 576`、H.264、30 fps、无音轨，每段约 3.87 秒。现有龙角入口仅在 Android 启用，iOS 需要单独接入并验收。[龙角播放器](../apps/mobile/lib/features/avatar/presentation/dragon_avatar_scene.dart) · [角色入口](../apps/mobile/lib/features/avatar/presentation/character_avatar_scene.dart) · [现有素材制作记录](../planning/demos/dragon-motion/README.md)

## 单角色素材上限

| 项目 | 已确认上限 |
| --- | --- |
| 动作数 | 最多 4 个，每个动作对应一段视频和一张封面 |
| 单段视频 | 不超过 5 秒 |
| 视频总时长 | 不超过 18 秒 |
| 视频与封面总大小 | 不超过 2 MiB（2,097,152 字节） |

| 动作 | 首轮时长配额 | 播放时机 |
| --- | ---: | --- |
| 待机 `idle` | 5 秒 | 默认循环，首个样片 |
| 倾听 `listening` | 4 秒 | 录音期间循环 |
| 思考 `thinking` | 4 秒 | 等待回复期间循环 |
| 说话 `talking` | 5 秒 | 语音播放期间循环 |

按最终入包视频时长和文件字节数验收。每个视频的时长计一次。单段 MP4 和单张 WebP 的制作预算分别为 450 KiB 和 60 KiB，满配四组共 2,040 KiB。轻笑、挥手等触发动作留待后续阶段。

## Seedance 生成规格

| 项目 | 首轮制作要求 |
| --- | --- |
| 模型与参数 | 在 Flova 选择 Seedance 2.5 Flash，画幅 `3:4`、分辨率 `720p`、时长 5 秒，使用首尾帧模式。后续动作按各自时长配额制作。 |
| 参考图 | 从获准使用的龙角立绘制备 `3:4` 参考图。上下补齐背景，保持人物的位置、大小和比例。同一张参考图同时用作首帧和尾帧。 |
| 构图 | 固定镜头、机位、景别和光照。按最终 `5:6` 居中裁切检查，上下各约裁去源画面高度的 5%。脸、龙角和动作重点避开裁切及渐隐区域。 |
| 动作 | 待机保持基准姿势，眨眼、轻微呼吸和发梢摆动放在中段，接近结尾时自然回到基准姿势。其他状态沿用角色外观、背景、构图和基准姿势。 |
| 制作记录 | 记录参考图版本、模型、提示词、生成参数、采用片段和重试次数。使用获准分发的素材供团队复测。 |

## Flova 提示词模板

每个角色先根据基准图填好角色卡。四个状态共用同一张基准图、角色卡和固定镜头约束。每次填写本段状态、时长和动作，并在 Flova 的任务参数中设置 Seedance 2.5 Flash、`3:4`、`720p` 及对应时长。首帧和尾帧都选同一张基准图。

```text
使用提供的同一张角色基准图作为首帧和尾帧。

角色卡
- 外观为 {脸型、肤色、瞳色、发型、体态和标志性特征}。
- 服装配饰为 {服装剪裁、主辅色、材质、配饰的形状和位置，
  以及哪些部分可以随动作轻摆、哪些应保持稳定}。
- 性格气质为 {性格关键词，以及用目光、表情、动作幅度和节奏表现这种气质的方式}。
- 基准姿势为 {身体和头部朝向、视线、肩线、手位、重心和嘴部状态}。

角色的外观、服装和配饰以基准图为准，四段动作都按同一角色卡表现。
采用固定镜头，保持人物位置、大小、景别和视角一致。
保持背景细节、光向、亮度和色调一致。画面只包含角色和基准图中的场景。
为最终 5:6 居中裁切保留边缘余量，脸部、角色标志性特征和动作重点位于画面中部。

本段状态为 {待机 / 倾听 / 思考 / 说话}。
本段时长为 {5 / 4 / 4 / 5} 秒。
本段动作是 {明确写出动作部位、方向、幅度和次数}。
从基准姿势自然起动，在中段完成动作，末段平滑回到同一基准姿势。
首尾对齐头部朝向、视线、肩线、手位、重心和嘴部状态，保持呼吸节奏连续。
```

待机用轻微呼吸、自然眨眼和发梢摆动。倾听用轻微抬眼或点头。思考时短暂移开视线再回正。说话用小幅、自然的唇部动作，尾段回到基准嘴形。每段只表达一个状态。

回正动作编入各段尾部，按四条视频交付。完整播放时，上一段尾部与下一段开头共用基准姿势。中途切换需在 App 内单独验证。若画面跳变明显，再验证播放器侧的短过渡，录音和回复语音按原有会话事件启动。

### 龙角角色填写示例

外观与服装取自现有待机图，性格气质以「温柔、从容」演示填写方式。[龙角待机图](../apps/mobile/assets/dragon_avatar/idle.webp)

```text
角色卡
- 外观为银白长发、紫色眼睛、分叉龙角和两侧龙翼。脸型和身体比例以基准图为准。
- 服装配饰为白紫色礼服、金色饰边、额前金色头饰和胸前紫金饰件。
  发梢和柔软衣料随呼吸轻摆，龙角、翼根和饰件保持原有形状及相对位置。
- 性格气质温柔、从容，有耐心陪伴的感觉。目光柔和，肩线放松，
  动作起落轻缓，表情变化细微。
- 基准姿势为身体和头部自然朝向镜头，双肩放松，双手自然垂放，
  重心平稳，目光看向镜头，嘴部自然放松。每段末尾回到这个姿势和眼神。
```

## App 入包规格

| 项目 | 交付要求 |
| --- | --- |
| 画面 | `480 × 576` 像素，`5:6`，居中等比裁切后缩放 |
| 视频 | MP4 容器，H.264，`yuv420p`，恒定 24 或 30 fps，移除音轨 |
| 封面 | `480 × 576` 的 WebP，从最终编码视频的首帧导出，与对应视频使用同名文件 |
| 待机时长 | 交付目标 4–5 秒，其他动作使用上表时长配额 |
| 播放与回退 | 复用正式 App 的龙角视频播放及生命周期处理。未准备好、解码失败或关闭动效时显示封面。聊天与通话的声音由现有语音链路播放。 |

裁切、缩放、转码和移除音轨统一在本地处理。优先保留符合要求的源帧率。样片先通过动作预览验收，再评估沉浸聊天的构图和循环表现，之后再决定正式待机的启用方式。

## 验收与交付

| 验收项 | 检查方法与判定 |
| --- | --- |
| 文件规格 | 用媒体工具读取最终文件的编码、像素格式、尺寸、帧率、时长和音轨。逐角色汇总动作数、视频总时长、视频与封面的字节数，并核对各自上限。 |
| 角色一致性 | 检查首帧、动作中段、尾帧以及预览和沉浸页的裁切。角色脸部、龙角、服装和背景保持一致，画面无拉伸或明显漂移，封面切到视频时构图保持一致。 |
| 循环与状态 | 在 App 内连续观察待机循环 10 次，接点无明显跳姿、闪帧或停顿。四动作齐备后，分别检查片段回正后的衔接和动作中途切换，覆盖待机、倾听、思考、说话及恢复待机。 |
| 离线播放和回退 | 断网时能播放本地视频。加载失败或关闭动效时显示对应封面。退后台、离开页面或换角色后停止旧视频，重新进入时正确恢复。 |
| 语音共存 | 视频播放时验证录音和回复语音，检查切换状态后视频正常且语音无额外中断。 |
| 真机与包体 | 分别记录 Android、iOS 真机的设备、系统、测试结果和 App 包体增量。模拟器结果单列，未具备条件的条目记为待验证。 |

按待机样片、预览接入、四动作联动及双端真机验收的顺序推进。提交筛选通过的入包视频、封面及对应改动，并记录每段素材的实测规格和验证结果。
