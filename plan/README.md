# 产品计划

本目录维护当前有效的产品规划，不维护任务执行状态台账。

| 文档 | 用途 |
| --- | --- |
| [product-plan.md](product-plan.md) | 产品定位、目标用户、核心体验、功能范围、阶段路线、质量要求和待决策事项 |
| [mobile-mvp-execution-plan-20261118.md](mobile-mvp-execution-plan-20261118.md) | Flutter AI 陪伴 MVP 的跨 Issue 执行计划、A～L 任务拆分、依赖关系及已有 PR 复用清单 |
| [android-integration-ci-execution-plan-20261118.md](android-integration-ci-execution-plan-20261118.md) | Issue #31 Android 模拟器集成测试 CI 的失败根因、修复方案、验收与执行步骤（待确认） |

## 使用边界

- 产品计划描述做什么、为什么做、分阶段做到什么程度。
- GitHub Issue 管理具体任务、讨论、依赖和验收；PR 记录实现及验证。
- 需要跨多个 Issue 协调时，再在本目录建立专项协作计划。
- 已接受的 ADR 优先于本计划；本计划中的待评审内容不视为已确认决策。
- 原始 Word 计划及生成工具保留在 planning/，仅供历史参考，不作为当前执行依据。
