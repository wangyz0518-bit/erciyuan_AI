## 使用边界

- 产品计划描述做什么、为什么做、分阶段做到什么程度。
- GitHub Issue 管理具体任务、讨论、依赖和验收；PR 记录实现及验证。
- 需要跨多个 Issue 协调时，再在本目录建立专项协作计划。
- 已接受的 ADR 优先于本计划；本计划中的待评审内容不视为已确认决策。
- 原始 Word 计划及生成工具保留在 planning/，仅供历史参考，不作为当前执行依据。
