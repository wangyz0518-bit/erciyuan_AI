## 打开原型

可直接在浏览器打开 HTML 文件，无需安装依赖或启动服务。也可使用 GitHub 文件页的预览能力查看源码和下载。

原型中的人物、消息、记忆摘要和导出内容均为合成演示数据。浏览器本地存储仅用于演示持久化，不代表正式数据存储或三层记忆已实现。
