    人物中心的三层数据

    原始记录保留完整历史；记忆层归纳并索引原始记录；身份层保存人物背景、性格与关系，每轮加载。需要细节时再从摘要回查原始记录。

    人物插画为 CSS 占位图，消息和记忆均为合成数据。浏览器本地存储及 JSON 下载仅用于演示；不代表正式记忆、云同步或生产级数据导出已经实现。语音入口不执行录音、TTS 或真实通话。
