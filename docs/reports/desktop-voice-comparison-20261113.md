# Qwen 与 CosyVoice 电脑端对比进展

> 状态：评审中

> 负责人：待团队分配

## 当前结论

用户试听反馈指出先前 ZipVoice 路线的自然度与跨表达音色一致性不足。本轮改为直接生成最终台词，已完成本地 Qwen 32 条生成和播放设备计时；CosyVoice 3.5 Plus / Flash 接口已准备，尚未配置北京区 API Key，未进行真实云端请求，没有本轮云端费用。配置已简化为默认只填 Key，业务空间 ID 为可选项。

当前 Qwen 非流式入口的热请求首段音频等待中位数 8.99 秒，不能满足实时陪伴聊天的响应目标。该结果只适用于本机当前推理配置，不能外推为所有 Qwen 部署的性能。音色一致性、自然度、情绪辨识均待人工盲听，不能宣布三模型优胜者。

## 参考与测试设计

固定 Qwen3-TTS 1.7B CustomVoice 的 Serena，制作 10.96 秒中性合成参考。其 55 个汉字经本地 SenseVoice 转写核对，忽略标点后无差异；音色审阅仍待人工完成。参考 SHA-256：`b5c8d7b1f0ccaa73d80ce9be757e47aed8464297c0877f2e1e6442d873fb5c8a`。

Qwen 直接使用 Serena；两款 CosyVoice 将分别从同一中性 WAV 创建模型绑定的音色。每种模型的四表达固定同一身份，只改变表达指令。参考为合成音频，不是真人录音；预设与复刻路径有差别，本试验比较该角色的可用性，不作为通用模型排名。

台词为 `experiments/voice_poc/screening-cases.csv` 的 8 句同文台词 × 4 表达，共 32 条；不挑选最佳生成。顺序种子 31、模型种子 21；四表达指令写入各轮 `experiment.json`。云端接口预期使用 PCM 24kHz 流式输出，输入为已经准备完整的短句。本轮不含真实对话大模型或语音识别的在线链路。

## Qwen 实测

Windows、i7-13620H、RTX 4060 Laptop 8GB、约 32GB 内存。`qwen-tts==0.1.1`、PyTorch `2.5.1+cu121`、BF16、SDPA、6 个 CPU 线程。已有 CUDA 环境覆盖 Qwen 依赖环境，具体运行方式见[指南](../guides/desktop-voice-comparison-20261113.md)。启动提示未安装 FlashAttention 和 SoX；本次生成未使用这两项，保留为环境限制，不将本配置当作性能优化上限。

| --- | --- | --- | --- |
| 有效 WAV / 请求 | 32/32 | 未接通 | 未接通 |
| 模型加载 | 7.20 秒 | 不适用本地加载口径 | 不适用本地加载口径 |
| 首次请求音频返回 | 11.84 秒 | 待测 | 待测 |

| 音色一致性 / 情绪效果 | 人工评分待完成 | 待生成及盲听 | 待生成及盲听 |

Qwen 当前接口返回整段波形，首段音频时间与整段生成时间相同，不是流式首包性能。RTF 大于 1 表示本配置生成速度慢于音频播放速度。样本量用于初筛，不作为服务等级保证。

播放使用系统默认的 **UU 远程虚拟音频设备 / MME**。设备 DAC 时间戳只提供播放估计，未测远程传输后的耳边出声、实体扬声器或手机扬声器。整轮报告的应用填零时长和 PortAudio underflow 均为 0；这不证明未来云端流式输出不会断续。

本地 SenseVoice 对 32 条合成音频的转写与台词有 1/424 字差异，属于自动辅助核对，不是正式人工字错率。参考、生成日志、转写、盲听评分表均保留在本机。

## 可复查材料与代码检查

- `.voice-local/comparison-reference/`：固定中性参考及其来源、哈希、生成指标。
- `.voice-local/comparison-qwen/`：32 条原始 WAV、逐条日志、参数与汇总。
- `.voice-local/comparison-qwen-blind/index.html`：当前仅 Qwen 的单模型盲听材料和 `scores.csv`，不能据此完成三模型对比。
- `.voice-local/comparison-qwen-four-expressions.wav`：同一句新台词按平静、开心、安慰、疑惑顺序串联，段间静音 0.5 秒。
- `.voice-local/comparison-asr.json`：辅助转写结果。

13 项离线单元检查通过：调用前预算检查、密钥异常日志处理、错误任务隔离、确认后发送文本、失败关闭且不自动重试、连接复用、PCM 分片、重复音色创建避免，以及只用 Key 时的默认域名和凭据隔离等。Windows DPAPI 本机加解密往返检查通过。协议测试使用假 WebSocket，与真实云端验收分开。
