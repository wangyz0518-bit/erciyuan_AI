# 文档索引

`docs/` 保存长期有效的项目知识，包括流程规范、调研、已确认决策、操作指南和接口约定。新增或调整文档时，同步更新所属目录索引和本文件。

## 入口

| 目录 / 文档 | 用途 |
| --- | --- |
| [process/](process/README.md) | 文档规范及稳定的协作流程 |
| [design/](design/README.md) | 人物中心产品原则、正式 Flutter/三层记忆架构设计、可点击原型与设计测试数据 |
| [research/](research/README.md) | 调研、选型和技术评估；结论不自动构成决策 |
| [decisions/](decisions/README.md) | 已提出或已确认的架构、技术决策（ADR） |
| [guides/](guides/README.md) | 环境配置、开发和排障指南，含 [iOS 正式 App 的 v3 语音安装指南](guides/ios-personal-team.md) |
| [账户、社区与角色分享](guides/community.md) | 正式 App 导航、多用户与角色分享、举报反馈和独立运营后台 |
| [正式 App 角色接入与验收](guides/character-onboarding.md) | 新增角色时使用的会话、动作素材和取景检查表 |
| [reports/](reports/README.md) | 特定版本或环境下的验证记录与测试证据 |
| [接口/](接口/README.md) | 接口契约草案及约定 |

[项目交付记录](reports/project-delivery-history.md)按阶段链接原始 PR、验证记录和角色制作演示。

龙角角色的[制作工程与样本](../planning/demos/dragon-layers/README.md)用于本机制作验证。已验证的翼尾待机动作见[Windows Viewer 记录](reports/dragon-live2d-minimal-20261114.md)。

## 文档约定

- 文档分类、命名、状态和索引规则见 [process/documentation.md](process/documentation.md)。
- 调研报告记录事实、选项和证据；最终选择写入 `decisions/`，并链接相关调研。
- 目录索引说明文档用途和状态；不在此处重复项目任务进度。
- 过时但有历史价值的文档保留并明确标注，不再作为当前依据。
