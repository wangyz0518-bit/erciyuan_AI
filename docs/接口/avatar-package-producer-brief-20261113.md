# 发给人物包制作方的联调任务书

> 状态：草案，配合人物资源包契约 v0.1 评审
> 日期：2026-11-13
> 负责人：待定
> 关联：C、A、#10

可将下面的任务说明连同契约、Schema 和描述文件示例交给同事或其大模型工具。制作方法不限，不要求搭建服务器；测试目标是一个外部资源包在 App 中正确显示和播放。

## 任务说明

请依据《人物资源包契约 v0.1》制作一个 Live2D 人物 ZIP，ZIP 根目录有 manifest.json。必须包含真实有效、相互配套的 MOC3 模型、PNG 纹理、model3.json 和 motion3.json；仅提供图片、概念设计图、视频或自定义 JSON 不算完成。

首轮可以使用有权用于测试的现成角色，优先确认制作工具能导出合法 Live2D 运行数据。先不用复刻白发龙角角色的外观，也不需要生成 15 套动作图。

至少交付：
1. idle：有呼吸与眨眼的自然待机循环。
2. wave：完整打招呼动作，播放一次并回到待机基准。
3. weight_shift：确有膝盖、脚或支撑状态变化的腿部重心动作，播放一次并回位。

目标环境为现有 Android Cubism Native 5-r.5，按契约 native-r5-basic-v1 范围导出。不同参数命名可以使用，但动作和分组必须引用模型里真实存在的参数。每个动作不超过 20 秒，注意头发、衣服和肢体遮挡。

必须按契约打包，所有文件引用均为包内相对路径，不引用你的本地绝对路径或网络地址。不要放 SDK、脚本、原始私密材料或音频。

如果你的工具只能生成图片/视频、不能导出有效 MOC3，请明确报告这个能力缺口；不要用改后缀或空文件伪装完成。若用现成模型，请如实列出哪些标准动作已验证、哪些仍缺失。

## 交付与说明

- 一个资源 ZIP。
- 一份简短交付说明：角色来源、实际制作/导出工具及版本、包 id/version、ZIP SHA-256、已验证与未验证项目。
- 最好附一段在制作方预览器中播放三个动作的录像；录像只是辅助证据，不能替代资源包。
- 不把尚未运行过的动作写成已经验证。
