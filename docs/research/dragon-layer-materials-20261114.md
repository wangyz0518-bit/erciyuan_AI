## 基准和目标

使用仓库已有 dragon-character-v1.png 为角色参考：成年女性、银白长发、紫眼、龙角与金紫头饰、白金长裙、双翼与尾巴。保持身份和服装，不增加暴露程度。左／右文件名一律指画面左／右，避免制作方混淆。

原图手靠近头部、长发和裙摆遮挡较多。完整挥手／换重心制作前可另定一个更易绑定的基准姿势，但必须经视觉核对；不能将独立生成的不同姿势硬拼成层。

## 第二阶段：自然呼吸、挥手和腿部重心

以下为命名建议，允许制作者根据遮挡关系增加图层；不硬性追求图层数量。

| 部位 | 建议独立素材 | 用途与补画要求 |
| --- | --- | --- |
| 后发 | hair-back-left / right / center | 补齐身后发束；与翼根分离 |
| 前发和侧发 | hair-front、hair-side-left / right | 允许小幅摆动，不含额头或耳朵残片 |
| 脸与耳 | face-base、ear-left / right | 头发后面的额头和耳根补完整 |
| 双眼 | 每眼 eye-white、iris、upper-lid、lower-lid | 按眨眼变形需要拆分，不能只贴闭眼图片冒充连续眨眼 |
| 眉毛 | brow-left / right | 与脸分离，支持基本表情 |
| 嘴 | mouth-line、mouth-inside，必要时上下唇 | 首轮不做精确音素，材质与范围由绑定者确定 |
| 头饰与角 | crown、horn-left / right | 小 Demo 可随头固定，避免无必要自由摇晃 |
| 颈肩与上身 | neck、torso-clothed | 衣着状态的连续胸腹和肩部，不要求生成裸身底图 |
| 衣服细节 | chest-fabric、waist-fabric、belt-jewel | 仅在呼吸／遮挡需要时拆，胸腹肩协调起伏；金饰不跟随过度拉伸 |
| 左右上臂 | upper-arm-left / right | 肩端、肘端保留隐藏重叠 |
| 左右前臂 | forearm-left / right | 肘部补画，不出现断裂接缝 |
| 左右手 | hand-left / right | 基准手型；挥手需要时另做兼容手型，避免多手指／缺指 |
| 裙后层 | skirt-back | 补齐两腿背后的衣料 |
| 裙前层与侧片 | skirt-front、skirt-side-left / right | 保持遮挡和衣服覆盖，防止腿动时穿帮 |
| 左右大腿 | thigh-left / right | 仅准备小幅活动所需遮挡余量，服装覆盖关系不改变 |
| 左右小腿 | shin-left / right | 膝连接自然，伸屈范围以画面验证为准 |
| 左右鞋脚 | foot-left / right | 保留落地锚点，避免换重心时脚底滑移 |
| 翼 | wing-left / right，必要时进一步拆骨架和膜 | 防止翼根露缝，与头发层次一致 |
| 尾 | tail-base / middle / tip（需要弯曲时） | 本轮整体尾可先用网格；拆段时隐藏搭接，不留硬切口 |

上表是“需要准备哪些内容”，不是要求同时生成几十张彼此独立的画。先确认一张基准图，再进行受约束编辑、提取和补画；独立重画整个部件容易导致比例和风格不一致。

## 文件与几何要求

- 交付参考图、独立透明 PNG、可编辑分层 PSD、图层说明和生成记录；PSD 是制作输入，MOC3 才是 App 运行资产。
- 完整制作建议统一画布 2048×2048、8 位 RGB/sRGB，具体按原图比例与编辑器性能确认；首轮生成样本允许先保留工具实际尺寸，任何缩放／定位都记录。
- 全尺寸导出时每层使用同一画布与原点；裁剪导出时必须记录位置与缩放。不能让生成工具各自居中后直接叠加。
- 背景为真实 alpha，不得烘焙棋盘格；半透明发丝边缘不得出现白边、彩边。
- 不带文字、UI、水印、背景阴影或其他部件碎片。每层命名唯一。
- 运动连接处应有隐藏重叠和合理补画；余量随目标动作幅度确定，不用固定像素数替代视觉检查。
- 分层 PSD 按 Cubism 规范整理图层与效果，导入后检查透明、颜色、绘制顺序和裁剪关系。
- 保存生成工具、提示词、参考版本、原始输出及修整记录，不声称实际没有使用的供应商。

## 验收

素材：逐层开关，确认没有重复器官／残影；叠回参考构图，记录脸、头饰、腿脚及翼根偏差。初始粗分层试验可记录近似对齐，但不能直接通过正式素材验收。

模型：必须有真实导出 MOC3，连续播放待机；翼尾变化不露缝，服装不穿模。后续增加自然胸腹呼吸、挥手和可见腿部换重心时分别验收，不能用整体平移／缩放替代独立腿部效果。

运行：记录编辑器导入、模型导出、查看器／App 加载分别是否通过。官方样例接入与自定义角色制作成果分开。Android/iOS 真机未做时必须注明。
