# 配置与密钥说明

> 仓库策略禁止直接提交 `.env` 文件，本文只记录配置项占位，不包含真实值。

## 原则

- 密钥由服务端持有，客户端不打包模型、语音、存储的密钥。
- 本地开发使用未纳入版本管理的配置文件或环境变量。
- 示例配置只写占位值；不要在 Issue、PR、日志或截图中粘贴真实密钥。
- 技术栈确定后，按实际框架补充配置加载方式和示例文件名。

## 当前配置项

| 变量 | 用途 | 位置 |
| --- | --- | --- |
| `CHAT_API_BASE_URL` | 对话服务地址 | 服务端 |
| `CHAT_API_KEY` | 对话模型密钥 | 服务端 |
| `CHAT_MODEL` | 对话模型标识 | 服务端 |
| `TTS_API_KEY` | 文字转语音密钥 | 服务端 |
| `ASR_API_KEY` | 录音转文字密钥 | 服务端 |
| `STORAGE_BUCKET` | 对象存储桶 | 服务端 |
| `STORAGE_ACCESS_KEY` | 对象存储访问密钥 | 服务端 |
| `STORAGE_SECRET_KEY` | 对象存储私钥 | 服务端 |
| `APP_API_BASE_URL` | 客户端访问的服务地址 | 客户端（非敏感） |

## 本地使用

技术栈确定前不创建统一配置文件。确定后：

1. 在仓库外或本地未跟踪文件中保存真实值。
2. 仓库内只保留示例文件，文件名按框架惯例确定。
3. 确认 `.gitignore` 已排除真实配置和密钥文件。
4. 提交前检查 `git status` 和 `git diff --cached`。
