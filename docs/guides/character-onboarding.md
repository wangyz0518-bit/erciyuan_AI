# 正式 App 角色接入与验收

新增可对话角色时，从正式 App 的人物选择页、沉浸聊天页和 v3 网关一起验收。若角色使用预渲染视频，再按下方规格交付动作素材。小芽是可运行的参考实现。

## 身份与在线会话

1. 给角色分配稳定的 ID。在启动时为新安装和已有安装补建缺少的角色及其 SQLite 时间线。重复启动后，已有角色、消息和时间线 ID 应保持一致。[启动入口](../../apps/mobile/lib/bootstrap.dart)
2. 在网关的 `PERSONAS` 中用该角色的网关 ID 写出名字、性格、说话习惯及互动边界。文字、按住说话和连续通话共用这份人设。新角色可沿用本地 ID。历史角色小星、小月的本地 ID 分别是 `star`、`moon`，网关沿用 `xing`、`yue`。[人设](../../services/model_gateway/gateway/providers.py) · [App 角色映射](../../apps/mobile/lib/immersive/chat_controller.dart)
3. 让 v3 的 HTTP 历史、WebSocket 会话和音色设置使用同一个网关 ID。首次可用默认音色，另选音色只影响当前角色。将新 ID 加入 Android 本机启动脚本的角色探测。在未配置 v3 时，按当前可用能力展示离线或兼容入口。[v3 契约](../接口/model-gateway-conversation-v3.md) · [Android 启动脚本](../../apps/mobile/tool/run_android_v4.ps1)

## 视频动作交付

| 文件或指标 | 入包要求 |
| --- | --- |
| 状态与命名 | 待机 `idle`、倾听 `listening`、思考 `thinking`、说话 `talking`。每个状态只交付一条全身 MP4 和一张同名首帧 WebP |
| 时长与体积 | 每段最多 5 秒，最多 4 组。视频总长最多 18 秒，四组视频和封面合计最多 2 MiB（2,097,152 字节）|
| 编码 | 视频和封面均为 480 × 576（5∶6）。MP4 使用 H.264、yuv420p、恒定 24 或 30 fps，移除音轨。封面从最终编码视频首帧导出 |
| 构图与循环 | 四态对齐人物中心、脚底线、镜头、服装和光照，循环接点自然回到基准姿势。动作幅度最大时，头顶、双手、衣摆、双脚和脚下背景仍在画面内 |

由 3∶4 原片居中裁到 5∶6 时，顶部至少留原片高度的 17%，底部至少留 20%，左右至少各留画宽的 8%。在 App 实际渐隐和聊天控件叠加后复核首帧、动作最大帧和尾帧。制作工具可按角色选用。[小芽入包素材](../../apps/mobile/assets/sprout_avatar/)

## 沉浸页取景与缩放

- 所有沉浸页角色都支持 0.8×–3.0× 连续缩放。双指和「人物大小」滑杆调节同一数值，保留「全身」「半身」快捷切换。带缩放的动作预览使用相同控件和构图。[缩放控件](../../apps/mobile/lib/features/avatar/presentation/avatar_zoom.dart)
- 全身以 1.0× 为基准，完整保留头顶和两只脚。半身从同一素材取头顶至腰线，按人物实际比例设定倍率与锚点。从半身逐渐缩小时，应依次露出下半身和双脚。
- 视频和封面共用取景变换。只调整倍率或切景别时继续播放当前片段。加载中、解码失败或关闭动效时显示当前状态的封面。角色语音由对话播放器输出。[共享播放器](../../apps/mobile/lib/features/avatar/presentation/dragon_avatar_scene.dart) · [小芽取景](../../apps/mobile/lib/features/avatar/presentation/sprout_avatar_scene.dart)

## 交付前走查

| 操作 | 通过条件 |
| --- | --- |
| 新安装、从旧版本升级，再重启 | 人物列表各有一项，每个角色沿用自己的历史。切到另一角色再返回，先前的消息、回听和音色绑定均属于原角色 |
| 在沉浸页发一条文字、按住说两句后松手、再进行连续通话并在播报中插话 | 回复符合所选人设。转写、回复、播放、插话停播和下一轮输入可用。三种输入落到同一角色的时间线 |
| 依次观察四态，再回到待机 | 录音时倾听，等待回复时思考，播放时说话，结束后回到待机。断网时本地动作可播放。退出、换角色或退后台后旧视频停止 |
| 观察全身与半身，然后在两端倍率之间来回缩放 | 全身可见双脚，半身可见头顶至腰线，下半身能随缩小重新显现。动作持续播放，封面切到视频时人物位置一致 |
