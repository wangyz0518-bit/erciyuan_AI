A 版先展示角色，点击「继续聊天」进入对话。B 版直接进入同一个聊天界面。两版均从左上角三横线打开 72 px 的半透明侧栏，图标下方配短标签。侧栏提供个人信息、角色首页、切换角色、聊天记录和设置。点侧栏外的画面或再点三横线即可收起。聊天输入框位于底部安全区上方。

评审时请试试这些操作。

1. 分别从 A、B 进入聊天，比较两种打开方式。
2. 展开侧栏，检查标签是否容易识别、背景透出多少。试试从设置切换镜头、从侧栏切换角色和打开记录。
3. 用右上角镜头按钮切换半身和全身，发送一条示例消息，观察人物表情、手势和文字的可读性。
4. 点击输入框，检查最近两条消息是否收成一条。收起键盘后，从消息区上拉也可以查看记录。

网页中的访客资料、回复、人物动作与桌面键盘为交互演示。正式 App 的表现需要真机验证，即时设计的导入效果也待确认。
