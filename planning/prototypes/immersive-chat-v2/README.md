A 版先展示角色，点击「继续聊天」进入对话。B 版直接进入同一个聊天界面。人物与雨夜场景铺满屏幕，文字区在同一画面上渐变压暗。默认镜头展示腰部以上，右上角可切换全身。

评审时请试试三个操作。

1. 分别从 A、B 进入聊天，比较哪种打开方式更适合日常使用。
2. 切换半身和全身，发送一条示例消息，观察人物表情、手势和文字的可读性。
3. 点击输入框，检查最近两条消息是否收成一条。收起键盘后，从消息区上拉或点「上拉看历史」查看记录。

网页中的回复、人物动作与桌面键盘是交互演示。正式 App 的表现需要真机验证，即时设计的在线导入效果也待团队确认。
