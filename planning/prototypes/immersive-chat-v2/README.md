打开原型直接进入最近的角色对话，底部左键切换打字，中间按住说话，右键开启通话。聊天页的半身和全身镜头从右上角切换。左上角的半透明侧栏可打开个人信息、角色切换、聊天记录和设置。

评审时请试试这些操作。

1. 按住中间按钮再松开，查看示例语音消息。点左侧键盘可打字，点麦克风切回语音。
2. 点右侧电话，在当前角色画面试试通话计时、静音和挂断。
3. 上拉消息区，检查历史面板的透明度和文字可读性。展开键盘时，聊天页只显示最新一条消息。
4. 切换角色，再刷新原型，检查能否回到最近的对话。示例对话保存在当前浏览器。

语音、通话、访客资料和桌面键盘为交互演示。即时设计的导入效果待确认，正式 App 的录音、通话和键盘行为需要真机验证。
