# 白发龙角角色预览素材

`dragon-character-v1.png` 是根据用户提供的游戏角色截图，经图像生成工具去除界面、补全人物及透明背景后生成的预览立绘（2026-11-13，1287 × 1222 RGBA）。保留白发、龙角、紫眼、白裙、翅膀和尾巴等外观；原角色设计来源于用户参考图，不能据此认定为项目原创角色或已取得正式发布授权。

当前只是单张图片，没有 PSD 分层、骨骼、MOC3、表情或物理绑定。`dragon_idle_motion.dart` 按这张图的构图定义局部形变区域，用连续网格实现小幅呼吸、重心与附属物摆动。换图需要重新校准区域，不能作为通用上传模型格式。
